# 项目立项与启动保存契约

日期：2026-10-22

## 实现范围

为实际绑定模板中无组件的项目资料节点提供节点级 `saveContract`（`project-profile/v1`），复用已注册的高风险 `project.update` 命令。字段仅来源于该模板的可见项目资料绑定，支持描述、优先级、项目等级、业务线、项目经理和项目排期；排期投影为 startDate/endDate。

成员与关注人保持专用命令；保存不完成节点，不公开 completionCommand。部分保存不会要求填写未修改字段。原有事务、项目版本、权限、幂等及审计继续由既有项目更新链路执行。

上下文提供 canonical 字段名称、标签和真实当前值，供外部 Agent 草稿校验及回读使用。CLI 校验项目、选中节点、节点版本、项目版本和字段白名单，并保留高风险预览确认规则。已完成/终止节点、关闭项目和显式只读节点不开放资料保存契约。

## 审查和修复

- 统一字段配置和旧 projectBasicInfoFields 不得合并，否则旧配置可能重新暴露隐藏字段；按 contentOrder 区分两种实际模板表示。
- 持久化字段值为空时仍使用可变 Map，避免补充项目真实资料值时抛出异常。
- Agent 发现阶段使用契约 canonical 字段，避免 project-description 和 description 混淆。
- 后端契约声明与 CLI 同时检查只读状态。
