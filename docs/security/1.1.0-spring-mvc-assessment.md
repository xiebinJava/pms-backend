# 1.1.0 Spring MVC 漏洞适用性评估

评估日期：2026-10-09。复核期限：2026-11-09。

## 范围与结论

仅针对发行镜像 `app/pms-backend.jar` 中的
`pkg:maven/org.springframework/spring-webmvc@6.2.19`。
依赖版本本身仍在官方受影响范围内；本结论是当前应用未具备漏洞触发条件，
不是宣称 Spring 6.2.19 已修复。

| CVE | 官方触发条件 | PMS 的评估依据 |
| --- | --- | --- |
| [CVE-2026-47884](https://spring.io/security/cve-2026-47884/) | 使用 XsltView，并有隐式视图名称的 `/**` 视图渲染映射 | 应用控制器均为 REST 响应，无 XsltView / XsltViewResolver；前端由独立 Nginx 提供 |
| [CVE-2026-47890](https://spring.io/security/cve-2026-47890/) | 使用 SSE 向客户端发送视图片段，并将攻击者控制的数据发送给其他用户 | 应用未提供 SSE 或视图片段流式渲染端点 |

Spring 官方分别评级为 MEDIUM 和 LOW；当前 Trivy 数据源把两项报告为 CRITICAL。
不通过调整扫描级别处理这一差异，而使用包版本与 JAR 路径共同限定的适用性例外。

## 可验证的依据与安全门禁

`SpringMvcSecurityApplicabilityIntegrationTest` 加载真实 Spring 应用上下文，验证：

- 不注册 XsltView 或 XsltViewResolver。
- PMS 请求处理器使用 RestController，不返回 View / ModelAndView。
- PMS 请求处理器不声明 SSE、ResponseBodyEmitter 或视图片段流式响应。

`.trivyignore.yaml` 只列出以上两项 CVE，有明确包版本、路径和复核期限。
CI 继续以退出码 1 阻止其他 HIGH / CRITICAL 发现，继续生成 SBOM。
既有 `ignore-unfixed` 策略保持不变。

复核时，或增加 MVC 视图、XSLT、SSE、流式视图片段、升级 Spring 依赖时，
必须重新评估并撤销或更新例外。长期依赖升级应单独安排兼容性验证，
不能把本次适用性评估作为永久替代。
