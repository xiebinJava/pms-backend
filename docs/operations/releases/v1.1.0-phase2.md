# PMS v1.1.0：组织与导入可靠性

本版本是单企业本地部署的第二阶段增量，数据库基线从 V1–V10 推进到 V1–V11。运行时仍只支持 OceanBase MySQL 兼容模式；H2 只用于自动化测试。

## 主要变更

- 新增 `sys_org_unit_history` 追加式组织变更历史，记录前后快照、操作人、请求 ID 和时间。
- 组织负责人（`sys_org_unit.leader_user_id`）与员工主归属（`sys_user_position.is_primary`）继续保持独立。
- 导入提交按任务 ID 幂等；失败批次整体回滚，并保存失败原因和时间。
- 新增服务端逐行错误报告下载接口：`GET /admin/import/{jobId}/errors.csv`。
- 新增组织历史查询接口：`GET /admin/org/{id}/history`。
- 校验脚本支持复用本地 OceanBase 镜像中的 `obclient`，不依赖临时下载 MySQL 工具镜像。
